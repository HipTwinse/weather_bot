# 🔄 РЕГЛАМЕНТ СИНХРОНИЗАЦИИ ПРОЕКТА (PC ↔ GITHUB ↔ VPS)

## 📌 Главный принцип
Единый источник правды — удаленный репозиторий GitHub. 
Домашний ПК и сервер VPS не передают файлы напрямую друг другу, вся синхронизация выполняется строго через коммиты в ветку `main`.

---

## 💻 СЦЕНАРИЙ 1: Поработал на домашнем компьютере → ухожу
Перед тем как выключить ПК, ОБЯЗАТЕЛЬНО отправить все изменения в репозиторий:
1. `git add .`
2. `git commit -m "описание изменений"`
3. `git push origin main`
*(После успешного завершения пуша компьютер можно выключать).*

---

## 📱 СЦЕНАРИЙ 2: Подключился со смартфона к Antigravity на VPS
1. **ПЕРВОЕ ДЕЙСТВИЕ** при старте сессии — подтянуть код, отправленный с домашнего ПК:
   - Выполнить: `git pull origin main`
   - *(Либо поручить агенту: «Сделай git pull и покажи текущий статус»)*
2. Провести работу/доработку проекта через чат или IDE.
3. **ПОСЛЕДНЕЕ ДЕЙСТВИЕ** перед закрытием клиента на телефоне:
   - `git add .`
   - `git commit -m "mobile update"`
   - `git push origin main`

---

## 🏠 СЦЕНАРИЙ 3: Вернулся домой, сел за домашний компьютер
**ПЕРВОЕ ДЕЙСТВИЕ** сразу после включения ПК:
1. Запустить общий скрипт `sync_all.bat` (или `update_all.bat`) на Рабочем столе (или выполнить `git pull origin main` в терминале проекта).
2. Все файлы на локальном ПК мгновенно обновятся до состояния, на котором остановилась работа на VPS.

---

## ⚡ ЗОЛОТОЕ ПРАВИЛО:
- **Сел за работу** (на любом устройстве) → сразу сделай pull (или запусти `sync_all.bat`).
- **Закончил работу** (перед выходом/выключением) → обязательно сделай push.
