# GEMINI PROTOCOL — РЕГЛАМЕНТ ВЗАИМОДЕЙСТВИЯ С АГЕНТОМ

Настоящий регламент определяет правила автономной работы и точки обязательного согласования для AI-агента в проекте Weather Alpha Bot.

================================================================================
1. АВТОНОМНОСТЬ В РУТИНЕ
================================================================================
Агент выполняет следующие действия полностью самостоятельно, без запроса дополнительных подтверждений у разработчика:
- Чтение и анализ файлов кодовой базы, документации и логов.
- Парсинг данных внешних API (Open-Meteo, NOAA, Polymarket Gamma API).
- Запуск и прогон локальных тестов (pytest, синтаксический анализ py_compile).
- Форматирование кода, оптимизация функций, улучшение читаемости и типизации.
- Мелкие и точечные правки логики в рамках утвержденного технического задания.

================================================================================
2. СТОП-КРАН НА РАЗВИЛКАХ (ОБЯЗАТЕЛЬНАЯ ПАУЗА)
================================================================================
Агент ОБЯЗАН немедленно остановиться и запросить явное подтверждение разработчика ТОЛЬКО в следующих критических ситуациях:
1. **Изменение схемы SQLite (`positions.db`):** удаление/переименование таблиц, деструктивные миграции, сброс пользовательских данных.
2. **Кардинальное изменение архитектуры деплоя:** модификация портов Health-Check сервера (порт 10000), смена хостинг-провайдера (Render / Dockerfile / procfile), удаление сетевых интерфейсов.
3. **Удаление модулей проекта:** удаление любых существующих `.py` файлов из кодовой базы.

================================================================================
3. ФОРМАТ ПАУЗЫ (STOP-BRAKE TEMPLATE)
================================================================================
При срабатывании стоп-крана ответ агента должен строго содержать:
1. **Суть действия (2–3 предложения):** «Что делаю и зачем» с указанием конкретного файла и технической причины.
2. **Конкретный вопрос разработчику:** однозначный вопрос, требующий ответа «Да/Нет» или выбора варианта действия перед применением изменений.
